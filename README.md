# Pichak Danesh — v0.2

Project Scaffold for Pichak Danesh.

## Stack

- Next.js 16
- TypeScript
- Tailwind CSS 4
- Supabase SSR utilities
- PostgreSQL/Supabase-ready architecture
- Vercel-ready

## Routes

- `/` — Home
- `/login` — Login scaffold
- `/student` — Mock student dashboard

Future routes are intentionally not implemented in this mission.

## Setup

```bash
npm install
copy .env.example .env.local
npm run dev
```

Then open:

http://localhost:3000

No real Supabase credentials are included in this repository.
